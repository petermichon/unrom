# Fonts

Self-hosted Inter Variable (UI) and Roboto Mono Variable (codenames/API), latin +
latin-ext subsets only, sourced from [Fontsource](https://fontsource.org).

Inter is © The Inter Project Authors and licensed under the SIL Open Font
License 1.1 (`OFL-inter.txt`). Roboto Mono is © Google and licensed under the
Apache License 2.0.

Space Grotesk (600, `unrom` glyphs only) is used for the wordmark, sourced from
[Google Fonts](https://fonts.google.com/specimen/Space+Grotesk) and licensed
under the SIL Open Font License 1.1 (`OFL-space-grotesk.txt`).

The favicon (`/favicon.svg`) uses the same `u` glyph. Its outline was extracted
from `space-grotesk-unrom.woff2` with fontTools and stored as a path, so it
matches the wordmark exactly without loading the font.

# Fonts

Self-hosted Manrope (interface and headings) and Roboto Mono (codenames, API
paths, numerals), latin + latin-ext subsets only, sourced from
[Fontsource](https://fontsource.org).

| Family      | Role                                  | Axes / weights   |
| ----------- | ------------------------------------- | ---------------- |
| Manrope     | Body copy, headings, interface chrome | variable 200–800 |
| Roboto Mono | Codenames, API paths, table numerals  | variable 100–700 |

Manrope is © The Manrope Project Authors and licensed under the SIL Open Font
License 1.1 (`OFL-manrope.txt`). Roboto Mono is © Google and licensed under the
Apache License 2.0.

The favicon (`/favicon.svg`) uses the Manrope 800 `u` outline stored as a path,
so it needs no font file. It sits on the site's periwinkle panel colour. Redraw
it from the Manrope `u` if the wordmark changes.
